## HSE Bank - Финансовый учет


## О проекте
Консольное приложение для учета личных финансов, разработанное для ВШЭ-Банка. Реализует модуль финансового учета с отслеживанием счетов, категорий и операций.

## Реализованная функциональность

### Основные требования 
- Создание, редактирование, удаление счетов
- Создание, редактирование, удаление категорий
- Создание, редактирование, удаление операций (доходов/расходов)
- Консольное приложение с интерактивным меню

### Дополнительная функциональность 
- Аналитика: подсчет разницы доходов/расходов за период
- Группировка операций по категориям
- Экспорт данных в CSV и JSON форматы
- Измерение времени выполнения операций

## Реализованные паттерны проектирования

#### Порождающие паттерны:
1. **Фабрика** (`DomainFactory`) - централизованное создание доменных объектов с валидацией
2. **Строитель** (`OperationBuilder`) - пошаговое создание сложных объектов

#### Структурные паттерны:
3. **Фасад** (`BankAccountFacade`, `CategoryFacade`, `OperationFacade`, `AnalyticsFacade`) - унифицированные интерфейсы для подсистем
4. **Прокси** (`RepositoryProxy`) - кэширование в памяти для репозиториев
5. **Декоратор** (`TimedCommandDecorator`) - добавление функциональности измерения времени

#### Поведенческие паттерны:
6. **Команда** (`Command` и реализации) - инкапсуляция запросов как объектов
7. **Шаблонный метод** (`DataImporter`) - определение скелета алгоритма импорта
8. **Посетитель** (`ExportVisitor`) - операции над объектами без изменения классов
9. **DI-контейнер** (`DIContainer`) - управление зависимостями

### Принципы SOLID и GRASP 

#### SOLID:
- **SRP**: Каждый класс имеет одну ответственность
- **OCP**: Система расширяема через новые импортеры/экспортеры
- **LSP**: Все реализации интерфейсов взаимозаменяемы
- **ISP**: Интерфейсы разделены по назначению
- **DIP**: Зависимости инжектируются через конструкторы

#### GRASP:
- **High Cohesion**: Логически связанный код сгруппирован вместе
- **Low Coupling**: Минимальные зависимости между компонентами

#### Структура проекта
```
hse-bank/
├── domain/          # Доменные сущности
├── factories/       # Фабрики создания объектов
├── facade/          # Фасады для работы с сущностями
├── commands/        # Паттерн Команда + Декоратор
├── importexport/    # Импорт/экспорт + Visitor
├── repository/      # Репозитории + Proxy
├── di/             # DI-контейнер
└── utils/          # Вспомогательные классы
```

### Запуск приложения

```bash
./gradlew build
java -cp build/classes/java/main com.hse.bank.Main
```

### Демонстрация работы
Приложение предоставляет интерактивное меню с возможностью:
- Управление банковскими счетами
- Управление категориями доходов/расходов
- Управление финансовыми операциями
- Просмотр аналитики и отчетов
- Экспорт данных в различные форматы
- Пересчитывает существующие балансы
