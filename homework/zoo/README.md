# Московский зоопарк - ERP система

Консольное приложение для учета животных и инвентаря зоопарка.

## Функциональность
- Добавление животных (обезьяна, кролик, тигр, волк) с проверкой здоровья
- Добавление предметов (компьютер, стол)
- Расчет общего количества еды
- Список животных для контактного зоопарка
- Поиск по инвентарному номеру
- Полная информация о зоопарке

## Запуск
```
./gradlew compileJava
java -cp build/classes/java/main org.example.Main

# Тестирование
./gradlew test

```
## Архитектура
## Основные компоненты:
Animal (абстрактный) - базовый класс животных

Herbo (травоядные) - Monkey, Rabbit

Predator (хищники) - Tiger, Wolf

Thing (абстрактный) - базовый класс предметов

Computer, Table

Примененные паттерны:
Factory - создание животных (AnimalFactory)

Repository - работа с данными (AnimalRepository)

Dependency Injection - управление зависимостями (DIContainer)

## SOLID принципы
S - Каждый класс имеет одну ответственность

O - Легко расширять новыми типами животных

L - Наследники могут заменять родительские классы

I - Интерфейсы разделены по назначению

D - Зависимости через DI контейнер
